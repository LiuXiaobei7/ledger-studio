# 怎么把这个项目传到 GitHub

> 给「不想敲命令」的人看的版本。整个过程只有两个动作：**复制一串字符**、**双击一个文件**。

---

## 先说清楚一件事

你的电脑**能上 GitHub**，之前传不上去不是你的问题。

原因是机器上同时开了两个代理：

| 代理 | 状态 |
| --- | --- |
| `127.0.0.1:7897`（系统代理，浏览器走这个） | ✅ 能访问 GitHub |
| `127.0.0.1:65002`（环境变量，命令行走这个） | ❌ 连不上 GitHub |

所以浏览器能打开 GitHub 网页，但命令行里的 `git push` 一定超时。**这个已经帮你修好了**——现在只对 `github.com` 这一个域名强制走 7897，你其他仓库不受影响。

---

## 第一步：拿一串「令牌」

令牌就是一串密码，作用是把仓库的写权限借给这个脚本用，用完可以随时作废。

1. 打开下面这个链接（已经帮你把权限勾好了，只要点一个按钮）：

   **https://github.com/settings/tokens/new?scopes=repo&description=ledger-studio**

2. 页面往下拉到底，点绿色按钮 **Generate token**

3. 页面上会出现一串 `ghp_xxxxxxxxxxxx`，**这个只显示一次**

4. 点右边复制图标，复制下来

> 如果第 1 步打开是要求登录，先登录你的 GitHub 账号。没有账号就先去 https://github.com/signup 注册一个，免费。

---

## 第二步：双击上传

打开项目文件夹，进到 `scripts`，双击：

```
上传到GitHub.bat
```

会出现一个黑窗口，它已经把该做的都做好了。窗口提示：

```
把令牌粘到这里，回车：
```

**右键粘贴**（或按 `Ctrl+V`）你刚复制的那串 `ghp_...`，然后回车。

然后就不用管了，等它自己跑完。中途会看到类似：

```
[3] 确认远端仓库
  ✓ 仓库已创建：https://github.com/你的名字/ledger-studio
[4] 推送代码
  ✓ 代码已推送
[5] 打标签 v1.1.3
  ✓ 标签已推送
[6] 创建 Release
  ✓ Release 已创建
[7] 上传安装包
  ✓ 附件已上传
```

**看到「全部完成」，就成了。** 窗口里会打印你的仓库地址，直接复制到浏览器就能看。

---

## 以后修改了东西，怎么更新？

再双击一次 `上传到GitHub.bat` 就行。脚本会自动：

- 判断仓库已经有了（不会重复创建）
- 把新改动推上去
- 如果版本号变了，自动打新标签、建新 Release、传新的 zip

**唯一的区别**：如果新版本要发 Release，需要你先把 `version.json` 里的 `version` 改一下（比如 `1.1.3` → `1.1.4`），脚本读的是那里。

---

## 懒得每次粘贴令牌？

在项目根目录新建一个文件，名字叫 **`.github-token`**（注意前面有个点），里面只放那一行令牌，保存。

以后双击 bat 就不用再输入了，脚本会自动读它。

> 这个文件已经在 `.gitignore` 里排除，不会被传到网上。但也别把它发给别人——它等于密码。

---

## 出错了怎么办

| 窗口里出现 | 意思 | 怎么办 |
| --- | --- | --- |
| `令牌无效或已过期` | 复制错了，或者已经作废 | 重新生成一个，注意别多复制空格 |
| `连不上代理` / `超时` | 代理软件没开，或者端口变了 | 先看右下角代理软件是否运行；端口不是 7897 就告诉我 |
| `创建仓库失败` + `403` | 令牌没有 repo 权限 | 重新生成，确认那一个勾选框是选中的 |
| `没有找到 Node.js` | 双击时找不到 node | 需要手动在 WorkBuddy 里运行，或告诉我 |
| 窗口一闪就没了 | 脚本提前报错 | 用「右键 → 在终端中打开」再输入 `上传到GitHub.bat` 运行，能看到完整报错 |

**任何报错，把窗口里的文字截图或复制给我，我来看。**

## 我实在不想弄

也可以把令牌直接发我，我在这边替你跑完。但要知道：

- 令牌等于密码，发出去就有风险
- 用完请立刻去 https://github.com/settings/tokens 把它 **Delete** 掉

相比之下，自己双击一次更安全，也更省事——就两步。

---

## 传上去之后能干什么

1. **别人能下载**：仓库页面点 `Code → Download ZIP`
2. **别人能看更新**：Release 页面会列出每个版本的改动
3. **应用内更新检查**：把 `assets/notice.js` 里的 `mode: 'demo'` 改成 `'live'`，再把 `USER` 换成你的 GitHub 名字，下次打开应用就会自动查新版本

第 3 条我建议等仓库传成功、你自己在浏览器能打开之后再改，那时候改起来心里有底。
